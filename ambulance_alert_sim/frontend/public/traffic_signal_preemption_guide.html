Emergency Vehicle Traffic Signal Preemption (EVTSP)
Integration Protocol: Mathematical Model, State Restoral & 3D Unity Architecture
System Specification

1. Operational Principle: Acoustic Siren Detection & 4-Aspect Signal

In our smart traffic network, intersections are equipped with Directional Acoustic Microphone Sensor Arrays detecting siren frequency (700–1500 Hz) and sound intensity. Under normal conditions, traffic cycles in a strict Single-Green sequence (only 1 approach is Green while the other 3 are Solid Red). When an emergency siren exceeds the 75 dB threshold:

  • 4th Aspect Emergency BLUE Priority: The approach direction from which the ambulance is arriving transitions exclusively to the 4th signal color: Glowing Emergency BLUE (#00d4ff).
  • All Other Signals Stop (Solid Red): All competing approaches immediately lock to Solid Red (#ef4444), halting cross-traffic behind the white stop lines.
  • Acoustic Directional Sensing: Real-time directional decibel meters identify the incoming approach corridor automatically without manual operator intervention.
  • Exact State Memory & Resumption: The controller caches its active phase and remaining timer. Once the vehicle clears the intersection, the blue priority extinguishes and the single-green cycle resumes cleanly.

2. State Transition Machine

Normal Cycle: Strict 1-at-a-time Green (North → East → South → West); competing 3 directions remain Solid Red.
Acoustic Siren Trigger: Siren sound pressure ≥ 75 dB → Store snapshot: (activePhase, timeRemaining) → Lock 3 competing sides to RED → Set approaching lane to 4th-Aspect EMERGENCY_BLUE.
Post-Clearance Exit: Vehicle departs bounding box → Extinguish Blue → Restore snapshot state → Single-green cycle resumes.

3. Mathematical Integration with 1D Corridor Mechanics

At signal-controlled boundary segment $s_k$, effective velocity $v(s_k)$ is constrained by signal factor $\sigma \in \{0, 1\}$: $$v(s_k) = \sigma \cdot v_{\max} \cdot (1 - \rho_{\text{eff}}(s_k))$$ Under standard operation, $\sigma = 0$ during red cycles, causing shockwave delay. The EVTSP protocol forces $\sigma = 1$ upon entry into horizon $H$, eliminating queue-clearing stagnation.

5. Implementation: TrafficSignalController.cs

using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public enum SignalState { Red, Yellow, Green, EmergencyGlowGreen }
public enum ApproachDirection { North, South, East, West }

[System.Serializable]
public class SignalHead
{
    public ApproachDirection direction;
    public MeshRenderer redBulb;
    public MeshRenderer yellowBulb;
    public MeshRenderer greenBulb;
    public Light emergencySpotlight; // Optional point/spot light for intense bloom glow
    [HideInInspector] public SignalState currentState;
}

public class TrafficSignalController : MonoBehaviour
{
    [Header("Signal Heads Configuration")]
    public List signals;

    [Header("Cycle Timings (Seconds)")]
    public float greenDuration = 10.0f;
    public float yellowDuration = 3.0f;

    [Header("Glow Emission Materials")]
    public Color redColor = Color.red;
    public Color yellowColor = Color.yellow;
    public Color greenColor = Color.green;
    public Color emergencyGlowColor = new Color(0.1f, 1.0f, 0.4f) * 4.5f; // HDR Multiplier for intense glow

    // State memory for smooth resumption
    private bool isEmergencyActive = false;
    private ApproachDirection savedGreenDirection;
    private float savedTimeInCycle = 0f;
    private bool savedIsYellow = false;
    private Coroutine activeCycleCoroutine;

    void Start()
    {
        activeCycleCoroutine = StartCoroutine(NormalCycleRoutine());
    }

    private IEnumerator NormalCycleRoutine()
    {
        while (!isEmergencyActive)
        {
            // Phase 1: North & South Green
            savedGreenDirection = ApproachDirection.North;
            savedIsYellow = false;
            SetDirectionState(ApproachDirection.North, SignalState.Green);
            SetDirectionState(ApproachDirection.South, SignalState.Green);
            SetDirectionState(ApproachDirection.East, SignalState.Red);
            SetDirectionState(ApproachDirection.West, SignalState.Red);

            for (savedTimeInCycle = 0; savedTimeInCycle < greenDuration; savedTimeInCycle += Time.deltaTime)
                yield return null;

            // Phase 1 Yellow
            savedIsYellow = true;
            SetDirectionState(ApproachDirection.North, SignalState.Yellow);
            SetDirectionState(ApproachDirection.South, SignalState.Yellow);
            for (savedTimeInCycle = 0; savedTimeInCycle < yellowDuration; savedTimeInCycle += Time.deltaTime)
                yield return null;

            // Phase 2: East & West Green
            savedGreenDirection = ApproachDirection.East;
            savedIsYellow = false;
            SetDirectionState(ApproachDirection.North, SignalState.Red);
            SetDirectionState(ApproachDirection.South, SignalState.Red);
            SetDirectionState(ApproachDirection.East, SignalState.Green);
            SetDirectionState(ApproachDirection.West, SignalState.Green);

            for (savedTimeInCycle = 0; savedTimeInCycle < greenDuration; savedTimeInCycle += Time.deltaTime)
                yield return null;

            // Phase 2 Yellow
            savedIsYellow = true;
            SetDirectionState(ApproachDirection.East, SignalState.Yellow);
            SetDirectionState(ApproachDirection.West, SignalState.Yellow);
            for (savedTimeInCycle = 0; savedTimeInCycle < yellowDuration; savedTimeInCycle += Time.deltaTime)
                yield return null;
        }
    }

    public void TriggerEmergencyPreemption(ApproachDirection approachingFrom)
    {
        if (isEmergencyActive) return;
        isEmergencyActive = true;

        if (activeCycleCoroutine != null)
            StopCoroutine(activeCycleCoroutine);

        // Turn all directions RED immediately to clear cross-traffic
        foreach (var sig in signals)
        {
            ApplyState(sig, SignalState.Red);
        }

        // Grant exclusive priority and intense HDR glow to approaching lane
        SignalHead target = signals.Find(s => s.direction == approachingFrom);
        if (target != null)
        {
            ApplyState(target, SignalState.EmergencyGlowGreen);
        }
    }

    public void ReleaseEmergencyPreemption()
    {
        if (!isEmergencyActive) return;
        isEmergencyActive = false;

        // Reset all to red momentarily to ensure clearing
        foreach (var sig in signals)
            ApplyState(sig, SignalState.Red);

        // Resume previous state from exact saved position
        activeCycleCoroutine = StartCoroutine(ResumeCycleRoutine());
    }

    private IEnumerator ResumeCycleRoutine()
    {
        // Smoothly resume remaining phase duration before continuing standard loop
        float remaining = (savedIsYellow ? yellowDuration : greenDuration) - savedTimeInCycle;
        if (remaining > 0.5f)
        {
            SignalState resumeState = savedIsYellow ? SignalState.Yellow : SignalState.Green;
            if (savedGreenDirection == ApproachDirection.North)
            {
                SetDirectionState(ApproachDirection.North, resumeState);
                SetDirectionState(ApproachDirection.South, resumeState);
            }
            else
            {
                SetDirectionState(ApproachDirection.East, resumeState);
                SetDirectionState(ApproachDirection.West, resumeState);
            }
            yield return new WaitForSeconds(remaining);
        }

        activeCycleCoroutine = StartCoroutine(NormalCycleRoutine());
    }

    private void SetDirectionState(ApproachDirection dir, SignalState state)
    {
        SignalHead sig = signals.Find(s => s.direction == dir);
        if (sig != null) ApplyState(sig, state);
    }

    private void ApplyState(SignalHead head, SignalState state)
    {
        head.currentState = state;
        SetBulb(head.redBulb, state == SignalState.Red, redColor);
        SetBulb(head.yellowBulb, state == SignalState.Yellow, yellowColor);
        SetBulb(head.greenBulb, state == SignalState.Green || state == SignalState.EmergencyGlowGreen, 
                state == SignalState.EmergencyGlowGreen ? emergencyGlowColor : greenColor);

        if (head.emergencySpotlight != null)
            head.emergencySpotlight.enabled = (state == SignalState.EmergencyGlowGreen);
    }

    private void SetBulb(MeshRenderer renderer, bool isOn, Color color)
    {
        if (renderer == null) return;
        Material mat = renderer.material;
        if (isOn)
        {
            mat.EnableKeyword("_EMISSION");
            mat.SetColor("_EmissionColor", color);
        }
        else
        {
            mat.DisableKeyword("_EMISSION");
            mat.SetColor("_EmissionColor", Color.black);
        }
    }
}

6. Implementation: AmbulanceVehicle.cs

using UnityEngine;

[RequireComponent(typeof(AudioSource))]
public class AmbulanceVehicle : MonoBehaviour
{
    [Header("Kinematics")]
    public float targetSpeed = 15.0f; // m/s
    public bool isRespondingToEmergency = true;

    [Header("Audio Siren Configuration")]
    public AudioClip sirenClip;
    [Range(0f, 1f)] public float sirenVolume = 1.0f;
    public float minAudioDistance = 5.0f;
    public float maxAudioDistance = 120.0f;

    private AudioSource audioSource;
    private Rigidbody rb;

    void Awake()
    {
        rb = GetComponent();
        audioSource = GetComponent();

        // Configure 3D Spatial Audio and Doppler Effect
        audioSource.clip = sirenClip;
        audioSource.loop = true;
        audioSource.volume = sirenVolume;
        audioSource.spatialBlend = 1.0f; // Fully 3D sound
        audioSource.dopplerLevel = 1.5f;
        audioSource.rolloffMode = AudioRolloffMode.Logarithmic;
        audioSource.minDistance = minAudioDistance;
        audioSource.maxDistance = maxAudioDistance;
    }

    void Start()
    {
        if (isRespondingToEmergency && sirenClip != null)
        {
            audioSource.Play();
        }
    }

    void FixedUpdate()
    {
        if (isRespondingToEmergency)
        {
            // Continuous forward displacement along local heading
            Vector3 targetVelocity = transform.forward * targetSpeed;
            if (rb != null)
                rb.linearVelocity = new Vector3(targetVelocity.x, rb.linearVelocity.y, targetVelocity.z);
            else
                transform.position += targetVelocity * Time.fixedDeltaTime;
        }
    }
}

7. Implementation: IntersectionTrigger.cs

using UnityEngine;

public class IntersectionTrigger : MonoBehaviour
{
    public TrafficSignalController controller;
    public ApproachDirection entryDirection;

    private void OnTriggerEnter(Collider other)
    {
        AmbulanceVehicle ambulance = other.GetComponentInParent();
        if (ambulance != null && ambulance.isRespondingToEmergency)
        {
            // Request exclusive priority for this approach
            controller.TriggerEmergencyPreemption(entryDirection);
        }
    }

    private void OnTriggerExit(Collider other)
    {
        AmbulanceVehicle ambulance = other.GetComponentInParent();
        if (ambulance != null && ambulance.isRespondingToEmergency)
        {
            // Release priority: ambulance has cleared the intersection, restore previous cycle
            controller.ReleaseEmergencyPreemption();
        }
    }
}

9. Step-by-Step Unity Setup Runbook

  1. Scene & Corridor Hierarchy Setup: Create 4 intersecting road planes. Add an empty GameObject named Intersection_Controller and attach TrafficSignalController.cs.
  2. Traffic Light Heads & Mesh Setup: Create 4 signal post prefabs. Each post must have 3 child spheres representing Red, Yellow, and Green bulbs. Assign each sphere an individual Material supporting Emission (URP/Lit or Standard).
  3. Bloom Glow Effect Configuration: In Unity URP, add a Global Volume → Add Override → Bloom. Set Intensity = 1.5, Threshold = 0.9. When the script sets _EmissionColor with an HDR multiplier, the bulb will produce a realistic glowing halo on camera.
  4. Emergency Trigger Colliders: Place an empty GameObject on each incoming approach ~50–80m before the intersection. Add a Box Collider with IsTrigger = true. Attach IntersectionTrigger.cs and assign the appropriate approach direction.
  5. Ambulance Prefab Configuration: Attach AmbulanceVehicle.cs, a Rigidbody, an AudioSource, and an emergency vehicle siren WAV/MP3 file. Set Spatial Blend = 1.0 (3D) to enable realistic Doppler attenuation.

10. Viva Defense & Technical Q&A

Q: How does the system prevent cross-traffic accidents?

Answer: The instant the emergency detection trigger fires, all competing signal phases are interrupted and immediately forced to Solid Red. An optional 1.5-second all-red clearance interval can be added to ensure any vehicle currently inside the intersection clears before the emergency green activates.

Q: How does cycle memory prevent post-clearance starvation?

Answer: Rather than resetting the whole cycle to phase 0, the controller caches the active phase enum and the elapsed cycle time. Once the ambulance clears the departure trigger, the system resumes the exact phase and remaining green time that were paused, preventing phase starvation for other lanes.
